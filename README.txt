拾店 · 静态托管包（电脑关机也能用）
==================================

这三个文件就是完整 app：
  index.html            全部界面 + 逻辑 + 5 张示例照片（已内联）
  manifest.webmanifest   装到桌面的名片（图标已内联）
  sw.js                  离线缓存

没有后端，所以这是"单机版"：盖章 / 位置 / 想去 / 我的章 / 离线都正常，
只是没有广场、点赞、评论（那些需要一台一直开着的服务器）。

--------------------------------------------------
怎么放到 GitHub Pages（约 3 分钟，一次性）
--------------------------------------------------
1. 打开 https://github.com/new
   仓库名填 shidian，选 Public，点 Create repository

2. 在新仓库页面点 "uploading an existing file"
   把这三个文件一起拖进去（不要拖文件夹），点 Commit changes

3. 仓库页 → Settings → 左侧 Pages
   Source 选 "Deploy from a branch"，Branch 选 main，目录 / (root)，Save

4. 等 1~2 分钟，地址是：
   https://<你的用户名>.github.io/shidian/

   手机 Chrome 打开这个地址 → 三个点 → 安装应用 / 添加到主屏幕。
   之后电脑关机、断网都能用（数据存在手机本地）。

--------------------------------------------------
以后要更新版本
--------------------------------------------------
在仓库里点 index.html → 右上铅笔 → 全选删掉 → 粘贴新内容 → Commit。
（sw.js 里的 VER 记得改成新名字，否则手机会一直用旧缓存）
